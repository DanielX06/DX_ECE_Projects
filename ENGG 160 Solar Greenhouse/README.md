# Modern Greenhouse Design
03/2025 - 05/2025

Goal:
The goal of this project was to design, and model a greenhouse prototype that would be optimized to be sustainable in Edmonton's climate. This project used AutoCAD modelling, 3D printing, and team based materials research to develop a functional and scalable design that demonstrates energy efficiency, and environmental control principles.



Key Tasks
- Design the complete greenhouse frame and panels in AutoCAD
- Convert AutoCAD model into STL format and prepare for printing using PrusaSlicer
- Compare materials for light transmission, UV resistance, and thermal insulation.


Learning Outcomes:
- Gained an understanding of AutoCAD 3D modelling and 3D printing
- Developed stronger collaboration, communication, and organizational skills by managing a four person team
